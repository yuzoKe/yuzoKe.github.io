Política de privacidade

A Secretária é um aplicativo de uso pessoal: o único usuário é o dono das contas Google que ele acessa.

  • Google Drive (escopo drive.file): só os arquivos que o próprio aplicativo criou, que são cópias de segurança cifradas dos seus dados.
  • Google Agenda: lê e cria eventos na agenda do dono da conta, a pedido dele.

Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de inteligência artificial. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
